## 1. Какую роль Карта играет в проекте THE RECEIVER?

Интерактивная карта мира (**World Map Modal**) — это **научно-технологическое ядро** и главный демонстрационный элемент проекта на хакатоне **NASA Space Apps Challenge** (номинация *Earth Jukebox*).

```
                      [ ИСПЫТАТЕЛЬНЫЙ КОНТУР КАРТЫ ]
                                     │
           ┌─────────────────────────┴─────────────────────────┐
           ▼                                                   ▼
   СПУТНИКОВЫЕ ДАННЫЕ NASA                             КОМПЬЮТЕРНОЕ ЗРЕНИЕ
   • 12 официальных слоев NASA SVS                     • 2D Canvas 720×360 px (EPSG:4326)
   • WMS-растры NASA GIBS                              • Оптическая плотность и RGB-энергия
   • Модель рельефа Blue Marble                        • Детектор спайков и аномалий
           │                                                   │
           └─────────────────────────┬─────────────────────────┘
                                     ▼
                      МОДУЛЯТОР СОНИФИКАЦИИ PIXELSONIFIER
       • Гармоническая сетка NASA-IMPACT: Аккорды C1–A6 (MIDI 24–93)
       • Яркость пикселя → Сила нажатия MIDI Velocity (35–127)
       • Высокая плотность аномалии → Бинарный барабан Chandra X-Ray
       • Долгота точки (-180°..+180°) → Стереопанорама (Left..Right)
       • Двухдвижковый аудиодиктор (Голос + Ушные маркеры Web Audio)
```

### Основные функции Карты в проекте:
1. **Реализация концепции Earth Jukebox («Земной музыкальный автомат»):**  
   Карта доказывает, что сонификация в проекте — **настоящая, а не декоративная**. Звук генерируется не из заранее записанных аудиофайлов, а синтезируется на лету из физических значений каждого пикселя спутникового слоя.
2. **Инклюзивный инструмент для незрячих исследователей (A11y First):**  
   Карта позволяет «видеть ушами»: перемещая курсор по планете, пользователь со 100% точностью определяет границы океанов, контуры материков, центры мегаполисов, эпицентры лесных пожаров и зоны экстремального потепления.
3. **Хроника климатического кризиса (2010 ↔️ 2026):**  
   Инструмент прямого сопоставления эпох: пользователь может в один клик сравнить состояние планеты в 2010 году (относительная стабильность) и в 2026 году (эскалация температурных куполов, таяние ледников и задымление атмосферы), услышав разницу в тональности, громкости и ритме.
4. **Сюжетный мост миссии:**  
   В сценарии проекта внеземной слушатель, поймавший в 1977 году пластинку Voyager Golden Record, разворачивает сканирующий луч на Землю наших дней. Карта — это экран бортового спектроанализатора корабля пришельца, расшифровывающего биосферные ритмы планеты.

## 2. Что именно показывает Карта?

Карта отображает глобальную проекцию Земли **Equirectangular EPSG:4326** с разрешением координатной сетки **720 × 360 пикселей**.

### А. Базовая подложка планеты
* **NASA Blue Marble: Next Generation** — фотографически точная глобальная композитная съемка поверхности Земли с океанической батиметрией.
* **Calibrated Earth Relief Fallback** — высококонтрастный векторный рельеф береговых линий материков и островов с координатной сеткой параллелей и меридианов (шаг 30°/60°), гарантирующий мгновенную работу даже при полном отсутствии интернета.

## 3. Математика сонификации: как пиксели становятся звуком

Преобразование пикселей в звук выполняется алгоритмами в [`src/audio/PixelSonifier.js`](file:///home/archandos/Desktop/nasa%20-%20hackaton/src/audio/PixelSonifier.js) без задержки (zero-latency W3C Web Audio API):

### 1. Оптическая плотность и яркость
Canvas считывает цветовой триплет $[R, G, B]$ под курсором или в сканируемой области:
$$\text{Luminance} = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$
Дополнительно анализируются спектральные доли энергии:
$$E_R = \frac{R}{R + G + B + 1}, \quad E_G = \frac{G}{R + G + B + 1}, \quad E_B = \frac{B}{R + G + B + 1}$$

### 2. Гармоническая шкала NASA-IMPACT (MIDI C1–A6)
Нормализованное физическое значение параметра $[0.0 \dots 1.0]$ отображается на 6-октавную ладовую сетку:
* Октавы от 1 до 6 ($C_1 = 24$ MIDI до $A_6 = 93$ MIDI).
* Лады: Мажорные и минорные трезвучия с интервалами `[0, 4, 7]` и `[0, 3, 7]`.
* Формула пересчета нот в физические частоты:
  $$f = 440 \times 2^{\frac{m - 69}{12}} \text{ Гц}$$

### 3. Сила нажатия (MIDI Velocity)
Громкость и плотность звука напрямую подчиняются стандарту **NASA-IMPACT «From Data to Melody»**:
$$\text{Velocity} = 35 + \text{NormalizedValue} \times (127 - 35)$$
* Минимальное фоновое значение (океан, чистый воздух) звучит тихо и прозрачно ($\text{Velocity} = 35$, амплитуда $\approx 0.27$).
* Экстремальная аномалия (эпицентр пожара, шторм) звучит с максимальной экспрессией ($\text{Velocity} = 127$, амплитуда $= 1.0$).

### 4. Бинарный ритм Chandra X-Ray (Binary Beats)
Если плотность спайков аномалии в исследуемом регионе превышает порог слоя ($\text{Spike Density} \ge 0.56 \dots 0.60$), срабатывает генератор бинарных щелчков `playChandraDrumBeat()`. Он добавляет ритмический пульс, имитирующий рентгеновские детекторы космической обсерватории Chandra при регистрации высокоэнергетических событий.

### 5. Стереопанорамирование по координатам долготы
Координата долготы пикселя ($\text{Lon} \in [-180^\circ \dots +180^\circ]$) жестко связана с положением источника в стереонаушниках:
$$\text{Pan} = \frac{\text{Lon}}{180} \quad (\text{от } -1.0 \text{ [слева]} \text{ до } +1.0 \text{ [справа]})$$
* Западное полушарие (Америка, Тихий океан) звучит в левом ухе.
* Нулевой меридиан (Гринвич, Европа, Африка) звучит строго по центру.
* Восточное полушарие (Азия, Индия, Памир, Австралия) звучит в правом ухе.

## 4. Функция сравнения эпох (2010 vs 2026: Климатическая дельта)

Главная аналитическая мощь Карты — **режим сравнительного анализа изменений во времени**.

### Как моделируется временная шкала:
1. **Прогресс аномалии во времени:**
   $$\text{YearProgress} = \frac{\text{Year} - 2010}{2026 - 2010} \in [0.0 \dots 1.0]$$
2. **Масштабирование радиуса и интенсивности шлейфов:**
   $$\text{AnomalyScale} = 0.58 + \text{YearProgress} \times 0.94$$
   $$\text{Radius} = \text{BaseRadius} \times (1.05 + \text{YearProgress} \times 0.85)$$
3. **Радиометрическая модуляция спутниковых растров:**
   * **2010–2014 гг. (Базовый уровень):** Контраст $0.88$, насыщенность $0.75$, приглушенные пастельные тона стабильной атмосферы.
   * **2022–2026 гг. (Кризисный уровень):** Контраст $1.20$, насыщенность $1.35$, тепловой кризисный фильтр `rgba(255, 60, 20, 0.18)` для температурных аномалий и дымовой аэрозольный шлейф.

### Что происходит при нажатии кнопки `COMPARE 2010 ↔️ 2026`:
1. Система переключает карту на 2010 год и воспроизводит фундаментальный базовый аккорд и параметры региона.
2. Делает паузу в 1200 мс для акустического разделения.
3. Переключает карту на 2026 год и воспроизводит диссонирующий кризисный аккорд повышенной громкости с бинарным ритмом.
4. В блоке телеметрии отображается сводка:
   * **Дельта в процентах:** например, `Delta: +48.2% Anomaly Increase`.
   * **Сдвиг аккордов:** `Chord Shift: D2m (Vel: 52) → A4m (Vel: 118)`.
   * **Физическое значение:** изменение параметра от минимального до критического.

## 5. Доступность для незрячих: Двухдвижковый Аудиодиктор

Проект построен по принципу **Universal Accessibility (A11y)**, делая карту доступной для людей с полной потерей зрения.

### А. Акустическая калибровка шкалы (`CALIBRATE KEY`)
Перед началом работы незрячий пользователь нажимает кнопку `CALIBRATE KEY` или выбирает цветные стопы шкалы внизу карты:
* Система поочередно проигрывает 4 ключевые точки палитры (Минимум $\to$ Среднее $\to$ Высокое $\to$ Экстремальное).
* Синтезатор проговаривает голосом: *«Stop 1: Minimum baseline 0 units, low calm chord... Stop 4: Extreme alert 140 units, sharp high-velocity warning chord»*.
* Пользователь запоминает слуховую шкалу и может интерпретировать любые последующие звуки.

### Б. Режим исследования наведением (`HOVER AUDIO: ON`)
* При перемещении курсора по карте (или пальца по сенсорному экрану) каждый пиксель мгновенно отзывается аккордом, отражая физическую величину в данной географической точке.

### В. Озвучивание кнопок и интерфейса (`VOICE: ON`)
* **Озвучивание фокуса и наведения:** Когда включен режим `VOICE: ON`, наведение мыши или клавиатурная навигация (`Tab`) на любую кнопку карты (выбор слоя, смена региона, зум, запуск сканирования, кнопки плеера) немедленно озвучивает ее название и функционал.
* **Архитектура двух движков:**
  1. **Основной голос (Web Speech API):** Работает на Windows, macOS, Android, озвучивая названия кнопок естественным голосом.
  2. **Отказоустойчивый синтезатор ушных маркеров (`playEarcon`):** Если в ОС (например, на минимальных дистрибутивах Linux Parrot/Debian) отсутствуют установленные языковые пакеты синтеза речи, аудиодвижок автоматически генерирует уникальные, короткие мелодические фразы (Earcons) на Web Audio API под каждый тип действия (`sonify`, `compare`, `scan`, `calibrate`, `layer`, `region`, `hotspot`).
* **Визуальный субтитр:** В верхней части экрана загорается плашка `[AUDIO READER ACTIVE: ...]`, дублирующая произносимый текст для слабослышащих или зрячих пользователей.

## 6. Режим планетарного сканирования (`SCAN PLANET`)

При нажатии на кнопку **`SCAN PLANET`**:
1. По всей высоте карты ($360$ пикселей широты) активируется вертикальный световой меридиан.
2. Меридиан непрерывно перемещается с запада на восток (от $-180^\circ$ до $+180^\circ$ долготы) с возможностью регулировки скорости.
3. Функция `analyzeCanvasColumn()` на каждом кадре считывает вертикальный срез планеты:
   * Вычисляет суммарную активность полушария.
   * Определяет самую яркую аномалию вдоль текущего меридиана.
   * Синтезирует непрерывную звуковую волну с плавной модуляцией стереопанорамы слева направо.
4. **Результат:** Планета звучит как гигантская виниловая пластинка — океаны дают тихие глубокие паузы, а континенты и грозовые фронты создают полифонические музыкальные всплески.

## 8. Использованные технологии и стандарты

* **Картографический стандарт:** WMS EPSG:4326 Equirectangular Projection (NASA GIBS).
* **Рендеринг данных:** HTML5 2D Canvas с прямым доступом к буферу пикселей (`getImageData`).
* **Аудиосинтез:** Native W3C Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`, `StereoPannerNode`, `BiquadFilterNode`).
* **Стандарт сонификации:** Методология **NASA-IMPACT «From Data to Melody»**.
* **Интерфейс и анимации:** React 19, Tailwind CSS v4, Framer Motion, Lucide Icons.
